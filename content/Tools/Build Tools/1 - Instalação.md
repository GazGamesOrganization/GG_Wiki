# Passo a passo: instalar pacote do GitHub na Unity

## 1. Copiar o link do repositório

1. Vá até o repositório no GitHub.
2. Clique no botão **Code**.
3. Copie o link HTTPS.

Link:

https://github.com/pumpedkk/GGTools.BuildTools.git

---

## 2. Abrir o Package Manager na Unity

1. Abra seu projeto na **Unity**.
2. No menu superior clique em:

Window → Package Manager

---

## 3. Adicionar pacote via Git URL

1. No **Package Manager**, clique no botão **+** no canto superior esquerdo.
2. Escolha:

Add package from git URL

3. Cole o link do GitHub.

Link:

https://github.com/pumpedkk/GGTools.BuildTools.git

4. Clique em **Add**.

---

## 4. Aguardar instalação

A Unity vai:

- baixar o pacote
- importar automaticamente
- mostrar ele na lista de pacotes

Se tudo estiver certo, o pacote aparecerá no **Package Manager**.
