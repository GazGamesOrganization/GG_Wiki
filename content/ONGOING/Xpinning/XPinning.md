O XPinning é um aplicativo de gameficação de aulas de spinning para auxiliar o professor realizar aulas mais engajantes para os alunos por meio de percursos 3D com integração com as bicicletas de spinning por meio de uma Antena ANT.

## Como Começar a Trabalhar

1. Clonar o projeto [Xpinning](https://github.com/GazGamesOrganization/Xpinning_Unity)do git e abrir na unity ultilizando a versão 2021.3.2f1 
2. Para testes comece da cena `Splash`

## Configurações

`Pastas`:  As pastas são organizadas em parte de `_Art` , `_Scenes`,`_Scripts` onde é armazenado o item da respectiva categoria
		1. Scripts avulsos são criados na pasta `_Scripts` já um sistema que tem vários scripts ganham uma pasta dedicada dentro de `_Scripts`
		2. Cenas são Organizadas em cenas de Menu nas pasta Menu e de Percurso na pasta Percursos 
`Commits`: Seguir padrão do [Conventional Commits](https://www.conventionalcommits.org/pt-br/v1.0.0/) `<tipo> [escopo opcional]: <descrição>`
`Branchs`: Seguir o padrão :
		- **Main** sendo a versão estável
		- **Bugfix** uma correção de bug rápida 
		- **Feature** Branch pra desenvolver Features
